Privacy Policy

Last updated: October 20, 2026

Who uses this app

This app is a personal, self-hosted assistant. Its only user is the owner of this site, who signs in with their own Google account.

What data it accesses

  • Google Calendar: to read, create and update the owner's events.
  • Google Contacts: to look up the owner's contacts.

How data is used

Data is used only to answer the owner's own requests (for example, "what do I have tomorrow?" or "add a meeting on Friday"). Requests are processed by the AI model provider the owner has configured, in order to generate answers.

Data is not sold, not shared with anyone else, not used for advertising and not used to train models by this app.

Storage

Sign-in tokens are stored only on the owner's private server. The owner can revoke access at any time at myaccount.google.com/permissions.

Google API Services User Data Policy

This app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
